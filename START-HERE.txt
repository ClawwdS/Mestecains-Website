ALDERWICK WEBSITE

1. Extract the entire ZIP (Windows: right-click > Extract All).
2. Open index.html in Chrome, Edge, Firefox or Safari.

All HTML, CSS, JavaScript and photos are included. Internet is only needed for the optional Google Fonts and external credit links. Your browser may limit saving the day planner when opening a local file; a local web server provides reliable storage.

To run a local server with Python installed, open a terminal in this folder and run:
python -m http.server 8000
Then visit http://localhost:8000

To publish: upload this folder contents to a static web host. No build step is required. Replace fictional town details and sample events before a real launch.
